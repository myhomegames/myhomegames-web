MyHomeGames on the Microsoft Store for Windows

← Back to news

MyHomeGames is now available on the Microsoft Store for Windows. The same self-hosted catalog for the games you already own on disk — installable and updatable from the Store like any other Windows app.

What you get

MyHomeGames helps you organize your video game collection: titles, consoles, accessories, and how you reach them from your PC. It does not sell or stream games; it catalogs what you already manage yourself.

Shipping through the Store makes first install and later updates simpler for Windows users. Search for MyHomeGames in the Store, or open the app page directly: apps.microsoft.com/detail/9nr449qz8r8f.

Already using it?

If you already run MyHomeGames on Windows, updating from the Store keeps you on the latest build without hunting zip packages by hand. If you are trying it for the first time, install from the Store and tell us what works — and what does not. Feedback, ideas, and bug reports are welcome.

In short

One more way to put the server on a Windows PC: the Microsoft Store listing for myhomegames-server, alongside the usual GitHub downloads for Windows, macOS, and Linux. Happy cataloging.
