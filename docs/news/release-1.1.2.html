MyHomeGames 1.1.2 is out

← Back to home

MyHomeGames 1.1.2 is out — a server and web client update focused on easier installs, richer catalog data, and smarter translations.

Install everywhere

  • Windows: unified package plus Microsoft Store publishing
  • Linux: APT/YUM packages via Cloudsmith (plus .deb, .rpm, and tarball)
  • macOS: .pkg installers (Apple Silicon and Intel) and Homebrew updates
  • If you open the web app and the server is unreachable, you see a download link for your platform

Multilingual catalog

  • Summaries and keywords translated on the server in your settings language
  • Automatic translation on search, detail, IGDB import, and edit save
  • Less reliance on on-the-fly browser translation — text is stored in metadata

Richer developers and publishers

  • Enriched IGDB company profiles: company size, legal name, country, status, and formerly relations
  • Shared company data, editable from developer/publisher views
  • More reliable parent/child company linking

Skins and updates

  • Installed skin version and server/web/skin compatibility
  • Update bell for official skins as well
  • Support for a collapsible library sidebar on narrow viewports

Clearer metadata reload

  • Bulk progress with tooltip, cancel, and resume after refresh
  • Per-item metadata reload (games, lists, and more)
  • Faster library cleanup and async recommended updates

Tunnel

  • On tunnel start, cloudflared auto-updates when needed

Get 1.1.2 from GitHub Releases or open the web app.
