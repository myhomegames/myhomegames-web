Import from a folder: build your library from disk

← Back to home

MyHomeGames is not a game store — it is a catalog of what you already own on disk. Import from a folder is built for that: point at a directory (a DOS collection, a Dreamcast scripts folder, a mix of ISOs and unpacked installs) and the server scans it to add titles to your library with the right launchers.

What it does

Pick a folder and start the import. MyHomeGames walks the tree, finds installs and disc images, and creates or updates game entries. You do not have to rename every COLC folder or every AI130.iso by hand: when reliable hints exist — file_id.diz, README, NFO, ISO volume metadata — the retail title comes from those signals, not from a bare folder acronym.

If you keep both a disc image (cd/….iso) and an unpacked copy under games/… for the same title, you get one library entry, not two — with launch paths attached to both dumps when that makes sense.

Built for real dumps

Home collections are messy: thousands of WAVs, voice packs, sound drivers, language subfolders. The scan keeps those as context for an install instead of turning every clip or data file into a phantom “game.” What matters stays: executables, launch scripts, ISO/CUE images, and the small text sidecars that name the title.

Mixed layouts work too: flat folders of .sh/.bat files, deep trees like dosprograms/games/…, CDs and RIPs side by side. Existing launch scripts can be re-attached to the right game even when the script name does not perfectly match the folder, so remote play still opens the correct dump.

Official catalog, if you want it

With an external catalog connected, recognized titles can pick up official metadata (cover, year, platforms). With the catalog off, import still creates entries from what is on disk — no hard dependency on a third-party account.

Resume without starting over

On large collections, import shows progress and can finish across multiple runs on the same folder. Work already done stays in a local cache: run Import again on the same path and it continues instead of rescanning everything from scratch.

In short

Import from a folder matches how you actually keep games on a NAS or external drive: one root, many dumps, one tidy catalog. Less manual renaming, fewer ISO-vs-unpacked duplicates, launchers that point at the right files — and a library that grows from your disk layout, not from typing titles one by one.
