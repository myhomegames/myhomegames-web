MyHomeGames is a self-hosted catalog for your own game library. It is not a store and does not distribute games. Most library data stays on the computer (or device) where you run MyHomeGames Server.

1. Who we are

This policy describes how personal data is handled when you use:

  • The website and Progressive Web App at myhomegames.vige.it (including the Android Trusted Web Activity package it.vige.myhomegames);
  • Optional cloud features operated for MyHomeGames (for example Cloudflare Access login and Cloudflare Tunnel hostname management via myhomegames-server.vige.it).

If you run MyHomeGames Server on your own machine or network, you (or your organisation) are typically the controller of the library data stored there. MyHomeGames only processes personal data for the hosted website and optional cloud services described below.

2. What data we process

2.1 Data on your home server (local)

The server you install stores library metadata, settings, and related files on that host (paths such as application metadata / content directories). That data generally does not leave your network unless you enable remote access (for example a tunnel) or manually copy it.

2.2 Website and PWA

When you open the site or app, standard technical data may be processed by the hosting stack (for example IP address, user agent, request timestamps) through CDN / hosting providers such as GitHub Pages and Cloudflare.

2.3 Optional Cloudflare Access and Tunnel

If you use Cloudflare Access to obtain a per-user tunnel run token:

  • Cloudflare processes your Access identity (typically email) under their terms;
  • MyHomeGames tunnel management may create DNS hostnames and a named tunnel associated with a username derived from your email, so your home server can be reached over HTTPS;
  • Your home server may store the tunnel run token locally to keep the tunnel running.

2.4 Optional third-party game metadata (IGDB)

If you look up games via IGDB-backed features, queries may be sent to IGDB (Twitch / IGDB services) or relayed through MyHomeGames infrastructure. Do not submit personal data in those searches beyond what is needed to find a game title.

2.5 Android / TV shells

Native shells (Android TWA, Samsung Tizen package) primarily open the hosted PWA. They do not replace your home server as the place where library data is stored.

3. Purposes and legal bases

We process data to:

  • Provide and secure the website, PWA, and optional tunnel login;
  • Operate DNS / tunnel configuration when you request remote access;
  • Improve reliability and prevent abuse of hosted endpoints;
  • Comply with applicable law when required.

Where the GDPR applies, typical bases include performance of a service you request (Art. 6(1)(b)), legitimate interests in securing and operating the service (Art. 6(1)(f)), and consent where required for optional features.

4. Sharing

We do not sell personal data. Processing may involve subprocessors that host or secure the service, including:

  • Cloudflare (Access, Tunnel, CDN / DNS as configured);
  • GitHub (site hosting / releases distribution);
  • IGDB / Twitch when you use game lookup features.

Remote play / streaming components you enable on your own network (for example Sunshine or Moonlight) are under your control and their own policies.

5. Retention

  • Home server data: retained until you delete it or uninstall the server.
  • Tunnel / Access-related records: retained while your tunnel and Access identity are active; you can request removal of tunnel hostnames and related Access identity used for MyHomeGames cloud login (deprovision).
  • Technical logs: retained only as long as needed for security and operations.

6. Your rights

Depending on your location, you may have rights to access, rectify, erase, restrict, or object to certain processing, and to data portability. For data stored only on your home server, exercise those rights on that system (or ask whoever operates it). For MyHomeGames hosted login / tunnel records, contact us as below.

You may also lodge a complaint with your local supervisory authority (in Italy: Garante per la protezione dei dati personali).

7. Children

MyHomeGames is not directed at children under 16. Do not use optional cloud login features if you are below the age required in your country without appropriate consent.

8. Changes

We may update this policy from time to time. The “Last updated” date at the top will change when we do. Continued use of the hosted site or cloud features after an update means you accept the revised policy.
